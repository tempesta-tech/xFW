# Tempesta Escudo Management Daemon

## Running

```
$ cd BUILD
$ ./tfw_mgr --help
Usage: tfw_mgr [options]:
  -h [ --help ]                         show this message and exit
  -d [ --debug ] arg (=0)               run in debugging mode
  -l [ --listen ] arg (=127.0.0.1)      address to listen on
  -p [ --port ] arg (=2244)             port to listen on
  -L [ --log ] arg (=/var/log/tempesta/manager.log)
                                        path to a log-file
```
